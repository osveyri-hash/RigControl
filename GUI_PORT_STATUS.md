Тесты: cargo test --features gui (profiles, fan_curve, system_panel).

## Сделано в v34 (вторая треть GUI)

- Профили (MainWindow.Profiles.cs + RigProfile.cs) -> src/profiles.rs (логика, без UI, с тестами) + Tab::Profiles «Профили».
  - Профили хранятся в settings.profiles как JSON в формате C#: неизвестные поля (MouseProfile и др.) не теряются.
  - При первом открытии создаются «Игра», «Работа», «Тихо» (как InitProfiles).
  - Карточки (двойной щелчок — применить), «+ Новый из текущих», имя, значок (Segoe MDL2 в файле, эмодзи в окне),
    флажки UseKeyboard/UseArgb/UseFans/UsePump/UseMouse, полное описание (ProfileSummary).
  - «Применить», «Записать текущие настройки», «Удалить» (последний удалить нельзя).
  - После применения пересоздаются PumpEditor и KeyPainter, обновляются цвета, auto_apply отправляет на устройства.
- Вентиляторы (MainWindow.Fans.cs + FanCurveEditor.cs) -> src/fan_curve.rs + новый ui_fans.
  - Режим для всех, режим по каждому каналу («Как для всех» = убрать из FanModes), «Своя скорость» (20–100 %).
  - Редактор кривой на egui Painter: сетка, пол 20 %, точки тянутся мышью, кривая только растёт, подсказка «°C → %».
  - evaluate / from_flat / to_flat / drag_point 1:1 с C#, есть тесты. Формат FanCurves тот же ([T0,P0,T1,P1,…]).
  - Канал можно добавить вручную по ID из LibreHardwareMonitor.

## v36.2 — датчики и вентиляторы через LibreHardwareMonitor
- sensors/ (C#, .NET 8, LibreHardwareMonitorLib 0.9.6 — как у C#-версии): помощник rigcontrol-sensors.exe,
  логика из Cooler/Telemetry.cs (CPU, GPU, плата, вентиляторы, SetSoftware/SetDefault). JSON по строке через stdin/stdout.
  build.bat собирает его в target\release\sensors. Закрылся stdin (выход, сбой, снятие задачи) — каналы отдаются плате.
- src/lhm.rs: один помощник на процесс, общий для всех потоков, снимок моложе 700 мс — из памяти, после ошибки повтор через 30 с.
- src/telemetry.rs: температура, мощность, частоты, Vcore CPU и видеокарта (в том числе AMD) — от LHM; sysinfo и nvidia-smi — запасные.
  Работает и для экрана помпы, ARGB «по температуре CPU» и страницы «О системе» (добавлены Vcore, лучшее ядро, хотспот, частота и напряжение GPU).
- src/fans.rs: порт UpdateFansAsync/FanTarget — режимы 0–6, кривые, 90 °C → 100 %, вниз не больше 3 %/с; свой поток, опрос платы
  только пока открыта страница или хоть один канал не на «Авто».
- Страница «Вентиляторы»: каналы с платы, обороты, % и «управляет программа», температура CPU на кривой, «Скопировать в другие».
- build.rs: release-сборка rigcontrol-gui.exe просит права администратора (как app.manifest в C#).
- Не сделано: значок файла .exe, плитки на «Устройствах», Curve Optimizer и паспорт моделей на «О системе»,
  управление вентиляторами из rigcontrol daemon (только из окна).

## v36.3 — автозапуск и вентиляторы без окна
- fan_curve и fans больше не требуют фичи gui (редактор кривой — только с gui): вентиляторами управляет и `rigcontrol daemon`

  «включено», когда задача запускает C#-версию, и пишет, какую программу она запускает.

  ярлык в «Пуск». Автозапуск включать из установленной копии: задача запоминает путь к exe.
